¿Qué es PhyroSense?

PhyroSense es un sistema de monitoreo inteligente diseñado para detectar señales de riesgo antes de que se conviertan en emergencias. Está pensado para espacios donde viven o trabajan personas: hogares, colegios, oficinas, comercios, talleres y bodegas.

Dispositivo PhyroSense

Un dispositivo portátil basado en ESP32 con sensores DHT22 (temperatura y humedad) y MQ-2 (humo y gases combustibles). Compacto, reutilizable y fácil de instalar en cualquier espacio.

Plataforma digital

La plataforma web recibe, almacena y analiza los datos de todos los dispositivos. Permite ver el estado de los espacios monitoreados, gestionar alertas y actuar a tiempo.

Detectar antes. Reaccionar a tiempo. PhyroSense da a las personas más tiempo para evacuar, pedir ayuda o actuar según corresponda.

Cómo funciona el sistema

El flujo completo es sencillo y automático:

  1. El dispositivo PhyroSense (ESP32) mide temperatura, humedad y nivel de humo/gases cada pocos segundos.
  2. Los datos se envían por WiFi a la plataforma mediante una solicitud HTTP.
  3. La plataforma recibe los datos, los guarda en la base de datos y analiza las condiciones.
  4. Si se detecta una situación de riesgo, se genera una alerta automáticamente.
  5. Tú, como usuario, ves toda la información en el Dashboard y puedes actuar en consecuencia.

Nota: todo este proceso ocurre en tiempo real, sin intervención manual.

El Dashboard

Al iniciar sesión entras al Dashboard. Es el centro de operaciones donde ves todo de un vistazo:

Estadísticas

Temperatura, humedad, humo/gases y nivel de riesgo actual del sistema.

Mapa interactivo

Cada punto en el mapa es un dispositivo PhyroSense. Su color indica el nivel de riesgo.

Alertas recientes

Las últimas alertas generadas. Acceso rápido al historial completo.

Estado de sensores

Indica si los dispositivos están conectados (Online) o sin comunicación (Offline).

Interpretación de los datos

Cada dispositivo PhyroSense mide varias variables. Los colores te ayudan a identificar rápidamente el nivel de alerta:

Temperatura Normal: bajo 30°C Elevada: 30‑35°C Crítica: sobre 35°C
Humedad Normal: sobre 45% Baja: 30‑45% Crítica: bajo 30%
Humo / Gases NINGUNO BAJO MEDIO ALTO

Niveles de riesgo (combinación de todo)

NORMAL RIESGO MODERADO RIESGO ALTO ALERTA

Nota: una alerta roja no significa que ya exista un incendio, pero sí que las condiciones son preocupantes y requieren atención inmediata.

Alertas: procedimiento recomendado

Cuando un dispositivo PhyroSense detecta condiciones anormales, el sistema genera una alerta. Aparecerá en el Dashboard y en la sección Alertas.

Pasos recomendados

  1. Revisar la alerta: leer el título y la descripción para saber qué dispositivo la generó y qué variable está fuera de rango.
  2. Confirmar recepción: si eres operador o bombero, haz clic en "Atender" para indicar que estás al tanto.
  3. Actuar según corresponda: si fue una falsa alarma, márcala como "Falsa". Si la situación está controlada, márcala como "Resuelta".
  4. Consultar historial: las alertas resueltas quedan registradas para futuras consultas y análisis.
Importante: si ves una alerta de nivel ALERTA y no estás capacitado para actuar, contacta inmediatamente a los servicios de emergencia. PhyroSense es una herramienta de apoyo, no reemplaza a los bomberos.

Gestión de dispositivos

Desde el menú Dispositivos (solo visible para administradores) puedes gestionar los equipos PhyroSense instalados.

  • Registrar un nuevo dispositivo: ve a Dispositivos → Nuevo dispositivo. Necesitarás el código y la API key que el ESP32 usará para identificarse.
  • Consultar estado: en la lista verás si están Online (conectados) u Offline (sin comunicación reciente).
  • Editar o desactivar: puedes modificar su ubicación o desactivarlo si ya no se utiliza.

Consejo: si un dispositivo aparece Offline, comprueba que tenga alimentación eléctrica y conexión WiFi. A veces basta con reiniciarlo.

Roles de usuario

Cada usuario de PhyroSense tiene un rol que determina lo que puede hacer dentro de la plataforma:

Rol Permisos
Administrador Control total: gestión de usuarios, dispositivos, configuración, alertas y acceso a todas las secciones.
Bombero Puede ver el mapa, los dispositivos y atender/resolver alertas. No puede crear usuarios ni modificar la configuración del sistema.
Operador Monitorea el sistema, visualiza todos los dispositivos y alertas, y puede confirmar y asignar alertas. No puede modificar usuarios ni configuración.
Observador Solo visualización: puede ver el Dashboard, el mapa y las alertas, pero no puede modificarlas ni gestionar dispositivos.

Nota: si necesitas cambiar tu rol, contacta con el administrador del sistema.

Consejos para usar PhyroSense

  • Activa las notificaciones: en Configuración puedes activar las notificaciones del navegador para recibir alertas en tiempo real sin estar mirando la pantalla.
  • Comparte tu ubicación: si activas la opción de ubicación, las alertas te mostrarán la distancia al dispositivo afectado, lo que ayuda a priorizar respuestas.
  • Usa los filtros: en el historial y en la sección de alertas puedes filtrar por dispositivo, fecha o nivel de riesgo para encontrar información rápidamente.
  • Revisa el historial: los datos históricos te ayudan a identificar tendencias y anticipar posibles problemas antes de que se conviertan en emergencias.
  • Actualiza la página: si notas que los datos no se actualizan, presiona Ctrl+F5 para recargar completamente la página y limpiar la caché.

¿Necesitas ayuda?
